# ex05.py — 인프런 인강 크롤링 & 인사이트 분석

## 개요

인프런(inflearn.com) 강의 목록을 Selenium으로 크롤링하고,
수강생 수·카테고리·강사 수익 등 다양한 기준으로 분석한 뒤
SQLite DB와 CSV 파일로 저장합니다.

---

## 크롤링 대상

| 페이지 | URL | 설명 |
|---|---|---|
| 인기순 | `https://www.inflearn.com/courses?order=POPULARITY` | 인기 강의 상위 노출 |
| 최신순 | `https://www.inflearn.com/courses?order=NEW` | 최근 등록 강의 포함 |

> 두 페이지를 합산 후 중복 강의는 자동으로 제거합니다.

---

## 수집 데이터 항목

각 강의 카드에서 다음 항목을 수집합니다:

| 항목 | 설명 | 예시 |
|---|---|---|
| title | 강의 제목 | `파이썬 완전 정복` |
| author | 강사(지식공유자) 이름 | `홍길동` |
| category | 카테고리 배지 | `프로그래밍 언어` |
| student_cnt | 수강생 수 (정수) | `15000` |
| rating | 평점 | `4.9` |
| review_cnt | 리뷰 수 (정수) | `113` |
| price_origin | 정상가 (원) | `55000` |
| price_curr | 현재가·할인가 (원) | `33000` |
| est_revenue | 추정 수익 = 수강생 × 현재가 | `495000000` |
| thumbnail | 썸네일 이미지 URL | `https://...` |
| href | 강의 상세 링크 | `https://www.inflearn.com/course/...` |

---

## 분석 항목

### [1] 인기 강의 Top 10
- **기준:** 수강생 수(`student_cnt`) 내림차순

### [2] 인기 카테고리 Top 5
- **기준:** 카테고리별 총 수강생 수 합산 내림차순

### [3] 강사 추정 수익 Top 10
- **기준:** 강사별 `수강생 수 × 현재가` 합산 내림차순
- ⚠️ 플랫폼 수수료·환불 미포함 단순 추정값

### [4] 수강생 많은 강의 Top 30
- **기준:** 수강생 수(`student_cnt`) 내림차순 (Top 10 과 동일 기준, 범위 확장)

---

## 저장 파일

### `inflearn_insights.db` (SQLite)

| 테이블 | 내용 |
|---|---|
| `courses` | 전체 수집 강의 원시 데이터 (crawled_at 포함) |
| `top_popular` | 인기 강의 Top 10 |
| `top_categories` | 인기 카테고리 Top 5 |
| `top_instructors` | 강사 추정 수익 Top 10 |
| `top_by_students` | 수강생 많은 강의 Top 30 |

> **DB Browser for SQLite** (무료) 로 열면 테이블 내용을 시각적으로 확인할 수 있습니다.

### `inflearn_insights.csv`

- 전체 수집 강의 데이터를 저장
- 인코딩: `utf-8-sig` (BOM 포함) → 엑셀에서 한글 깨짐 없음

---

## 실행 흐름

```
1. 크롤링
   ├── 인기순 페이지 (scroll_steps=12)
   └── 최신순 페이지 (scroll_steps=8)
        ↓ 중복 제거 후 합산

2. 분석
   ├── 인기 강의 Top 10
   ├── 인기 카테고리 Top 5
   ├── 강사 추정 수익 Top 10
   └── 수강생 많은 강의 Top 30

3. 콘솔 출력

4. 파일 저장
   ├── inflearn_insights.db
   └── inflearn_insights.csv
```

## 기술 스택

| 라이브러리 | 용도 |
|---|---|
| `selenium` | SPA(Next.js) 렌더링 후 HTML 수집 |
| `beautifulsoup4` | HTML 파싱 및 CSS 셀렉터 추출 |
| `sqlite3` | 결과 DB 저장 (Python 내장) |
| `csv` | CSV 파일 저장 (Python 내장) |

---

## 주의 사항

- 인프런은 **Mantine UI + Next.js** 기반 SPA이므로 일반 `requests` 요청으로는 강의 카드가 로드되지 않습니다. Selenium으로 실제 브라우저를 구동해야 합니다.
- CSS 클래스명(`mantine-*`)은 사이트 업데이트 시 변경될 수 있으므로, 크롤링 실패 시 셀렉터를 재확인해야 합니다.
- 추정 수익은 **단순 계산값**으로 실제 강사 수익과 다릅니다.
