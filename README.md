# 🚀 김태혁의 기술 스택 정복기 (MyProject_KTH)

국비지원 과정을 통해 학습한 **Frontend, Backend, Database** 기술들을 체계적으로 정리하고 기록하는 공간입니다. 기초부터 실무 수준의 프로젝트까지의 성장 과정을 담고 있습니다.

---

## 📚 Repository Map

| 카테고리 | 주요 내용 | 기술 스택 |
| :--- | :--- | :--- |
| **[Springboot](./springboot)** | 블로그 제작, 시큐리티 적용, JPA 실습 | Java, Spring Boot, MariaDB, JPA |
| **[React](./react)** | 컴포넌트 기반 웹 프런트엔드 실습 | React.js, JavaScript, JSX |
| **[JavaScript](./javascript)** | 사칙연산 프로그램 및 DOM 조작 기초 | Vanilla JS, HTML5, CSS3 |
| **[Python](./파이썬-날씨분석)** | 기상 데이터 분석 및 시각화 프로젝트 | Python, Pandas, Matplotlib |
| **[SQL](./sql)** | 데이터베이스 설계 및 쿼리 최적화 | MySQL, MSSQL |
