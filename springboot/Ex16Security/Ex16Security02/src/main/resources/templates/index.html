로그인여부(isAuthenticated())
isAuthenticated() 함수가 true면 span text가 표시된다. false면 사라짐.
로그인여부(isAnonymous())
isAnonymous()함수가 true면 span text가 표시된다. false면 사라짐.
로그인여부(isAuthenticated()) : 인증 후 - 로그인 상태
로그인여부(isAnonymous()) : 인증 전 - 로그아웃 상태
로그아웃 로그인
권한/역할/인가(hasRole('USER')) :
일반회원입니다.
권한/역할/인가(hasRole('ADMIN')) : 관리자입니다. 관리자 페이지로 이동(회원목록)
