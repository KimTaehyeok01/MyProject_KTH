Domain Design

도메인 설계

📖 Book 엔티티
  • id, title, author, publisher
  • isbn — 유니크 제약
  • category, totalQuantity, availableQuantity
  • publishDate, description
  • 대출 시 decreaseAvailable() / 반납 시 increaseAvailable()
👤 Member 엔티티
  • id, userId — 유니크
  • password — BCrypt 암호화 저장
  • userName, email, phone
  • userRole — ROLE_USER / ROLE_ADMIN
  • joinDate — LocalDate 자동 기록
📋 Loan 엔티티
  • userEmail, userName
  • book — @ManyToOne(fetch = LAZY)
  • loanDate / expectedReturnDate — 대출일 +14일
  • returnDate — null이면 대출 중
  • loanStatus — BORROWED / RETURNED
🌐 SnsUser 엔티티
  • 소셜 로그인 전용 회원 테이블
  • Kakao / Naver 공급자 구분
  • OAuthAttributes 클래스로 공급자 정규화
  • 일반 Member 테이블과 완전 분리 구조
KAKAO NAVER
📌 Loan → Book : N:1 연관관계
📌 Member와 SnsUser : 인증 방식별 분리 테이블

Feature 02

도서 관리 기능

🔍
도서 조회 (일반 회원)
  • 전체 목록 — 페이지당 12건 페이징
  • 키워드 검색 — 제목 또는 저자명
  • 카테고리 필터링
  • /api/books/** — 비인증 접근 허용

수량 관리 로직
  • totalQuantity — 전체 보유 수량
  • availableQuantity — 실시간 대출 가능 수량
  • 대출 시 자동 감소, 반납 시 자동 증가
🛡️
도서 관리 (관리자 전용)
  • POST /admin/books — 도서 등록
  • PUT /admin/books/{id} — 도서 수정
  • DELETE /admin/books/{id} — 도서 삭제
  • @Secured("ROLE_ADMIN") 어노테이션 보호
  • ISBN 유니크 제약 — 중복 등록 방지
  • 도서명, 저자, 출판사, 카테고리 관리
  • 전체 도서 현황 통계 제공
07 / 11
Feature 03

대출 / 반납 기능

📤
대출 처리 로직
  • 대출 가능 수량 확인 (availableQuantity > 0)
  • 중복 대출 방지 — 동일 도서 대출 중이면 차단
  • 반납 예정일 = 대출일 + 14일 자동 계산
  • 대출 상태 BORROWED 로 기록
  • 가용 수량 자동 감소
📥
반납 처리 로직
  • 본인 대출 여부 검증
  • 이미 반납된 도서 중복 반납 방지
  • 실제 반납일 returnDate 기록
  • 상태 RETURNED 로 변경
  • 가용 수량 자동 증가
구분 조회 범위 접근 권한 비고
내 대출 현황 대출 중인 도서만 ROLE_USER 상태 = BORROWED
내 대출 이력 전체 대출 기록 ROLE_USER 반납 포함
전체 대출 현황 모든 회원 대출 기록 ROLE_ADMIN 관리자 전용

Security

보안 설계

🔐 JWT 인증
• 로그인 성공 시 JWT 발급
• HttpOnly 쿠키에 저장
• 매 요청마다 토큰 검증
• Security 필터체인 앞단 삽입
🛡️ 경로별 권한 분리
ADMIN /admin/** USER /my/**, /loans/** PUBLIC /, /login, /api/books/**
🌐 OAuth2 소셜 로그인
• Kakao / Naver 연동
• OAuthAttributes 정규화
• CustomOAuth2UserService
• 성공/실패 핸들러 분리
SecurityConfig.java
// CSRF — 쿠키 기반 토큰 방식 .csrf(csrf -> csrf .csrfTokenRepository( CookieCsrfTokenRepository .withHttpOnlyFalse())) // 경로별 인가 설정 .authorizeHttpRequests(authz -> authz .requestMatchers("/admin/**") .hasRole("ADMIN") .requestMatchers("/api/books/**") .permitAll() .requestMatchers("/", "/login") .permitAll() .anyRequest().authenticated() ) // JWT 필터 — Security 필터 앞에 삽입 .addFilterBefore( new JwtAuthenticationFilter(jwtUtil), UsernamePasswordAuthenticationFilter.class) // OAuth2 소셜 로그인 .oauth2Login(oauth -> oauth .loginPage("/login") .userInfoEndpoint(u -> u .userService(customOAuth2UserService)) .successHandler(snsSuccessHandler()) );
