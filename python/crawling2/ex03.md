# ex03 — 셀레니엄으로 네이버 뉴스 헤드라인 크롤링

## 개요

`selenium` 라이브러리의 **WebDriver**를 사용해 네이버 뉴스 IT/과학 섹션에서  
헤드라인 기사 **제목 5개**와 **링크 5개**를 자동으로 가져옵니다.

> 네이버 뉴스처럼 React 기반의 동적 사이트는 `requests + BeautifulSoup`으로  
> 데이터를 가져올 수 없어 실제 브라우저를 제어하는 셀레니엄이 필요합니다.

---

## 사전 준비

```bash
pip install selenium
```

> Chrome 브라우저가 설치되어 있어야 합니다.  
> Selenium 4.x 이상은 ChromeDriver를 자동으로 관리하므로 별도 설치가 불필요합니다.

## 코드 흐름

```
1. Chrome 브라우저 실행
2. 네이버 뉴스 섹션 페이지 접속
3. 헤드라인 목록이 DOM에 로드될 때까지 최대 10초 대기 (WebDriverWait)
4. CSS 셀렉터로 헤드라인 <a> 태그 요소 목록 수집
5. 상위 5개 요소에서 text(제목)와 href(링크) 추출
6. 콘솔 출력 후 브라우저 종료
```

---

## 핵심 코드 설명

### 1. CSS 셀렉터

```python
HEADLINE_SELECTOR = "ul[id^='_SECTION_HEADLINE_LIST'] div.sa_text > a"
FALLBACK_SELECTOR = "div.sa_text > a[href*='/article/']"
```

| 셀렉터 | 설명 |
|--------|------|
| `ul[id^='_SECTION_HEADLINE_LIST']` | ID가 `_SECTION_HEADLINE_LIST`로 시작하는 `<ul>` (사이트 배포마다 접미사가 달라질 수 있어 `^=` 사용) |
| `div.sa_text > a` | 헤드라인 텍스트 영역 안의 직계 자식 `<a>` 태그 |
| `FALLBACK_SELECTOR` | 메인 셀렉터로 5개 미만이 잡힐 때 사용하는 폴백 |

### 2. 동적 로딩 대기 (WebDriverWait)

```python
wait = WebDriverWait(driver, 10)
wait.until(
    EC.presence_of_all_elements_located((By.CSS_SELECTOR, HEADLINE_SELECTOR))
)
```

`time.sleep()` 고정 대기 대신 요소가 실제로 나타날 때까지만 기다리므로  
더 빠르고 안정적입니다. 10초 초과 시 `TimeoutException`이 발생합니다.

### 3. 제목·링크 추출

```python
for headline in headlines[:5]:
    titles.append(headline.text.strip())
    links.append(headline.get_attribute("href"))
```

| 메서드 | 반환값 |
|--------|--------|
| `.text` | 태그 안쪽의 보이는 텍스트 (기사 제목) |
| `.get_attribute("href")` | 완성된 절대 URL |

### 4. 윈도우 한글 깨짐 방지

```python
if hasattr(sys.stdout, "reconfigure"):
    sys.stdout.reconfigure(encoding="utf-8")
```

Windows 환경에서 기본 콘솔 인코딩(cp949)으로 인한 한글 깨짐을 방지합니다.

## 주의 사항

- 네이버는 **자동화 탐지**를 운용하므로 반복 실행 시 접근이 차단될 수 있습니다.
- 사이트 HTML 구조가 변경되면 CSS 셀렉터를 개발자 도구(F12)로 다시 확인해야 합니다.
- 헤드라인 목록의 ID 접미사(`_as5w9` 등)는 배포마다 달라질 수 있으므로 `^=` 부분 일치 셀렉터를 사용합니다.
